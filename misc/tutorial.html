1. Folder & file structure

All content changes happen in index.html. CSS and JS only need to be touched if you're changing the design or adding new behavior.

2. Image sections

Applies to: Static Maps, Spatial Analysis, and 3D Models.

Adding a new image

  1. 1Drop the image file into the appropriate subfolder under assets/images/.
  2. 2Open index.html and find the section you want to update. Each section is marked with a comment like <!-- ── Static Maps ──.
  3. 3Copy an existing <article class="carousel-slide"> block and paste it after the last slide, before the closing </div></div> of the track.
  4. 4Update the src and alt on the <img> tag, and fill in the title and description in the caption.
  5. 5Add one more <button class="carousel-dot"> to the .carousel-dots div below the carousel.

A complete slide looks like this:

index.html 
<article class="carousel-slide">
  <div class="slide-content">
    <div class="slide-media slide-media--image">
      <img src="assets/images/static-maps/your-file.jpg"
           alt="Brief description of the map">
    </div>
    <div class="slide-caption">
      <h3 class="slide-title">Map Title</h3>
      <p class="slide-desc">One or two sentences about the map.</p>
    </div>
  </div>
</article>

Replacing a placeholder with a real image

Find the slide that has a <div class="img-placeholder"> inside it and replace the entire div with a single <img> tag:

before 
<div class="slide-media slide-media--image">
  <div class="img-placeholder img-placeholder--map">
    <p class="ph-label">Map Image</p>
    <code class="ph-hint">assets/images/map-1.jpg</code>
  </div>
</div>
after 
<div class="slide-media slide-media--image">
  <img src="assets/images/static-maps/your-file.jpg"
       alt="Descriptive alt text">
</div>
Supported formats: JPG, PNG, WebP, and GIF all work. For best performance, export at the resolution you need — these images fill the full slide height so anything around 1800px wide is plenty.

3. Iframe sections

Applies to: Full Stack and Custom Widgets.

Wiring a live app into a slide

Find the slide you want to update. Inside its .slide-media div you'll see a <div class="frame-placeholder">. Replace the entire placeholder div with a single <iframe> tag:

before 
<div class="slide-media slide-media--frame">
  <div class="frame-placeholder">
    ...
  </div>
</div>
after 
<div class="slide-media slide-media--frame">
  <iframe src="https://your-django-app.com"
          title="Project Name"
          loading="lazy"></iframe>
</div>
Cross-origin note: The app being embedded needs to allow iframing. If the Django app is on a different domain from the portfolio, make sure its server sends X-Frame-Options: ALLOWALL or a permissive Content-Security-Policy: frame-ancestors header. Apps on the same domain (e.g. both on GitHub Pages subdomains) should work without changes.

Adding a new iframe slide

Same process as image slides — copy an existing <article class="carousel-slide"> block, paste it in, swap the URL, update the caption, and add a dot. A complete iframe slide:

index.html 
<article class="carousel-slide">
  <div class="slide-content">
    <div class="slide-media slide-media--frame">
      <iframe src="https://your-app.com"
              title="Project Name"
              loading="lazy"></iframe>
    </div>
    <div class="slide-caption">
      <h3 class="slide-title">Project Name</h3>
      <p class="slide-desc">What this app does and the stack behind it.</p>
    </div>
  </div>
</article>

4. Adding or removing slides

Adding a slide

  1. 1In index.html, find the section and copy any existing <article class="carousel-slide">…</article> block.
  2. 2Paste it immediately before the closing </div></div> of the .carousel-track.
  3. 3Update the content inside the new slide.
  4. 4Scroll down to the .carousel-dots div for that section and add one more button:
<button class="carousel-dot" role="tab"
        aria-label="Slide 5" aria-selected="false"></button>

Removing a slide

  1. 1Delete the entire <article class="carousel-slide">…</article> block for that slide.
  2. 2Remove one <button class="carousel-dot"> from the section's .carousel-dots div.
Keep the counts in sync: the number of .carousel-slide elements must always equal the number of .carousel-dot buttons in the same section. Mismatches won't break anything but the indicator will be off.

5. Writing More Info modal content

By default the modal shows the slide's title and the short caption description. To add extended copy — methodology, tools used, client context, anything longer — add a data-modal-detail attribute directly to the <article> tag:

index.html 
<article class="carousel-slide"
         data-modal-detail="Adirondack Park boundary rendered using
LiDAR-derived elevation data. Produced in QGIS with a custom hillshade
layer and contour styling at 50m intervals. Final output at 24×36 inches,
300 DPI, for print.">

The modal title is always pulled from the .slide-title element — no separate attribute needed for that.

Multi-paragraph text: Use \n\n (two newlines) between paragraphs inside the attribute value. The modal renders them as visual line breaks automatically.

6. Updating titles and descriptions

Inside each <article class="carousel-slide"> block, the caption lives at the bottom:

index.html 
<div class="slide-caption">
  <h3 class="slide-title">Your Title Here</h3>
  <p class="slide-desc">One or two sentences shown under the image.</p>
</div>

The slide-title also populates the modal heading automatically, so keeping it accurate matters for both the caption and the modal.

The section subtitles ("Cartographic design and print-ready map production", etc.) are in the .section-sub paragraph just below each section's <h2> tag — find the section by its comment and edit the text directly.
